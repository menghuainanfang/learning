# 每日学习

本目录用于安排每日任务和汇总学习闭环，不复制各课程已有主档案。

## 目录分工

- `00-每日任务`：当天的任务单与完成状态。
- `01-数学能力诊断`：数学诊断索引、阶段报告和复检结果；完整课程内容仍保存在 `数学` 目录。
- `02-技术英语`：英语训练索引、阶段输出和复测结果；完整英语主档案仍保存在 `语言学习/英语`。
- `03-学习闭环与周复盘`：每周掌握证据、Obsidian 精炼事项与 Anki 候选审核记录。

## 使用原则

每天早上的定时任务只发布当天可以完成的任务，不替学习者作答。学习过程先在对应长期聊天中完成；当天结束后再把真实作答、提示程度和下一步批量归档。只有经过核对且值得长期记忆的单点知识进入 Anki 候选。
