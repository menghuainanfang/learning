# Learning

个人综合学习仓库，用于集中保存课程地图、交互学习文档、学习笔记、练习记录与学习工具。

## 目录

- `数学/`
  - 数学分析
  - 高等代数
  - 数值分析
  - 泛函分析
  - 复变函数
  - 数学物理方程
  - 差分方程
- `计算机科学/`
  - 计算机基础
  - 数据结构与算法
  - 数据库系统
- `语言学习/`
  - 英语
- `论文精读/`
  - 论文原文、阅读入口与精读记录
- `考研打卡/`
  - 数学分析与高等代数复习记录
- `每日学习/`
  - 当前每日学习入口与归档说明
- `Plan/`
  - 原英语学习计划，暂时保留

根目录保留专题学习讲义与训练题，项目代码、生成结果和站点静态资源不纳入本仓库。

文档按“学科 → 课程”分类。课程地图与具体交流文档放在对应课程目录中，后续新增学科沿用同样结构。

## 公开说明

本仓库不收录机器学习与 AI 课程目录，也不收录桌面教材库。部分学习文档保留本地材料位置作为个人阅读入口，在其他设备上可能不可直接访问。
